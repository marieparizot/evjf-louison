# EVJF de Louison

Site à partager avec les invitées : 6 villes à moins de 2 h 15 de Paris (Reims, Deauville-Trouville, Lille, Bruxelles, Bordeaux, Lyon), avec logements, spas, chefs à domicile et soirées classés par gamme de prix (€, €€, €€€). Chaque invitée peut liker ses préférés.

- Données : `scripts/build_data.py` → `data/evjf.json` + `data/embedded_data.js` (hors-ligne)
- Likes partagés : renseigner l'adresse Firebase Realtime Database dans `config.js`
